## Recomended changes
- Scoring engine currently started everyone with -3 points per day for the duration of the challlenge, so in this case -3 for 7 days means a -21 starting score. I don't think that is very human friendly for the leaderboard. I think the logic that is happening is the scoring engine starts everyone with -3 for duration of the challenge. Then when a participant submits a valid score it over writes that score with their submission. I think instead everyone should start with zero, and then when they have a valid submission that is over written. Or when they do not have a valid submission it is overwritten with -3.
